# Makambako Yetu

Makambako Yetu is a Flutter community-discovery app concept for finding local
businesses, services, transport information, and community resources in one
place.

The current app includes:

- A Makambako-branded home screen with quick links into discovery.
- Explore categories with text search and category filters.
- A saved-items page for categories a user bookmarks during the session.
- A simple profile and app information page.

The categories are starting points for future local listings; the app does not
currently provide verified business records, live transport data, or community
announcements.

## Run the app

```sh
flutter pub get
flutter run
```

## Run tests

```sh
flutter test
```
